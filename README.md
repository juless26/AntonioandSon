# Antonio & Son Landscape Design and Maintenance

A one-page website, written in plain HTML and CSS. There is nothing to install or build.

## Files

- `index.html` is the page.
- `styles.css` holds the colors, type and layout.
- `thanks.html` is the page a visitor sees after sending the estimate form.
- `images/` holds the photos.
- `netlify.toml` tells Netlify to publish this folder as it is.

## Before the site goes live

Search `index.html` for `TODO`. Each one marks text that needs a real value from Antonio:

1. The two service lists
2. Contractor license number, if he has one
3. Photos. The ones in `images/` are placeholders until Antonio sends photos of his own work. The four named `sample-*.jpg` are computer-generated.

## Estimate form

The form uses Netlify Forms. Netlify detects it on the first deploy. Requests then appear in the Netlify dashboard under Forms, where you can add an email notification to Antonio.
